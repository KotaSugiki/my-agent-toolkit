# GitHub・GiteaでのIssue起票とPR作成

操作先の確認、認証・権限、重複確認、Issue・PRの記載事項と作成後の確認は、[共通ルール](../templates/AGENTS.md#issue起票とpr作成)に定めています。必須の規約は、スキルの自動呼出しに依存させません。

操作手順は [github-gitea-operations](../skills/github-gitea-operations/README.md) にまとめています。Issue起票・PR作成を依頼したときに自動呼出しの対象となり、名前を指定して使うこともできます。目的・前提条件・使い方はスキルのREADME、エージェント向けの手順と詳しい操作例はスキル本体と付属資料を参照してください。

このツールキットで作業する際は、[プロジェクト固有の規約](repository-rules.md)にも従います。他のプロジェクトでは、そのプロジェクトの規約を使います。

共通のAGENTS.mdは引き続き手動で導入します。操作用スキルの導入は [Skillsの導入方法](skills-installation.md)を参照してください。この案内文書を導入先へコピーする必要はありません。
