# 引き継ぎ先の起動形

選んだ CLI の節だけを読んでください。一覧にない名前は、末尾の未登録の節を読んでください。

起動前に、その CLI の `--help` を確認してください。この文書と違えば、ヘルプを優先してください。必要なフラグがヘルプに無い場合は起動しないでください。

ここに書いたフラグは、2026-10-15 にこの環境で `--version` と `--help` を実行して確認しました。ファイルの変更と、フォークに書かれた確認コマンドだけを自動承認します。各節の迂回用フラグは、利用者がその実行で指定したときだけ使ってください。

プロンプトの本文は `prompt.md` に置き、コマンドライン引数へ埋め込まないでください。ヘルプが標準入力を読むと示している CLI は、`prompt.md` を標準入力にしてください。示していない CLI は、短い引数で `prompt.md` の絶対パスを読ませてください。

プロセスの作業ディレクトリは、フォークの作業ディレクトリにしてください。

## Claude Code

確認したバージョンは 2.1.300 です。実行ファイルは `claude` です。

非対話は `-p` です。ヘルプには、パイプに使えることと、非対話ではワークスペースの信頼確認を出さないことが書かれています。`prompt.md` を標準入力にしてください。

ファイル書き込みの権限モードは `--permission-mode acceptEdits` です。`--permission-mode` の選択肢は `acceptEdits`、`auto`、`bypassPermissions`、`manual`、`dontAsk`、`plan` です。

確認コマンドの実行で承認待ちになる場合は、起動を続ける前に利用者へ伝えてください。全権限の迂回は `--permission-mode bypassPermissions` で、利用者がその実行で指定したときだけ使ってください。

## Gemini CLI

確認したバージョンは 0.64.0 です。実行ファイルは `gemini` です。

非対話は `-p` です。ヘルプには、`-p` の文字列が標準入力のあとに連結されると書かれています。`prompt.md` を標準入力にし、`-p` には標準入力の指示に従う短い文だけを渡してください。

ファイル変更の承認モードは `--approval-mode auto_edit` です。ヘルプでは、編集ツールを自動承認するモードです。選択肢は `default`、`auto_edit`、`yolo`、`plan` です。

確認コマンドの実行で承認待ちになる場合は、起動を続ける前に利用者へ伝えてください。全権限の迂回は `--approval-mode yolo` で、利用者がその実行で指定したときだけ使ってください。

## Codex

確認したバージョンは codex-cli 0.161.0 です。実行ファイルは `codex exec` です。

プロンプト引数を省略すると、標準入力を指示として読みます。`prompt.md` を標準入力にしてください。

サンドボックスは `-s workspace-write` です。選択肢は `read-only`、`workspace-write`、`danger-full-access` です。作業ディレクトリは、プロセスの作業ディレクトリに加え、`-C` でも同じパスを指定してください。

承認待ちを人に戻さない指定は `--approve-for-me` です。ヘルプでは、承認要求を workspace-write サンドボックスの自動レビューへ回します。全権限の迂回は `--dangerously-bypass-approvals-and-sandbox` で、利用者がその実行で指定したときだけ使ってください。

## Cursor

確認したバージョンは 2026.10.14-941492e です。実行ファイルは `cursor-agent` です。短い名前の `agent` は使わないでください。2026-10-15 のこの環境では、`agent.exe` が `C:\Users\dxpro\.grok\bin\agent.exe` を指していました。

非対話は `-p` です。ヘルプには、書き込みとシェルを含むツールが使えると書かれています。標準入力をプロンプトとして読むとは書かれていないため、`-p` の引数は `prompt.md` の絶対パスを読む短い指示にしてください。作業ディレクトリは `--workspace` に同じパスを指定してください。

全権限の迂回は `--force` で、利用者がその実行で指定したときだけ使ってください。

## 未登録の CLI

利用者から、実行ファイル、プロンプトの渡し方、ファイル変更と確認コマンドを自動承認する権限の指定を受け取ってください。受け取ったフラグが `--help` にあることを確認してから起動してください。ヘルプに無いフラグは作らないでください。

全権限を迂回する指定は、利用者がその実行で出した場合だけ含めてください。
