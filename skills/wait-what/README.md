# wait-what

Matt Pocockさんの `wait-what` を日本語化したスキルです。直前の説明が分かりにくいときに、背景を補って平易な日本語で説明し直します。

## 使い方

説明が分かりにくいと感じた直後に、ユーザーが明示的に呼び出します。

- Codex: `$wait-what`
- Claude Code: `/wait-what`

背景を補い、一文ごとの内容と専門用語が理解しやすい日本語で説明し直します。会話で使われている言葉と、その意味に合わせて説明します。
