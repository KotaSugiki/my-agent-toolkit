# スタイルガイド

図の色・書体・トークンの唯一の出典です。`type-*.md` と `index.md` は役割名(`paper`、`ink`、`accent` など)で参照し、16進値はこのファイルだけが決めます。値は `design-system/document.css` の `--mb-*` に合わせています。`document.css` を更新したら、この表も更新します。

ライトのみです。`type-*.md` にある dark の列・`C_light`・terminal skin の記述は読み飛ばします。

## トークン

| 役割 | 値 | 対応する html のトークン | 用途 |
|---|---|---|---|
| `paper` | `#FFFFFF` | `--mb-surface` | ノードの塗り、ラベルのマスク。図は白地の `.mb-figure-frame` に載る |
| `paper-2` | `#FAF9F6` | `--mb-bg` | ゾーン・コンテナの地、副次の塗り |
| `ink` | `#111110` | `--mb-ink` / `--mb-border` | 主要な文字と線 |
| `ink-strong` | `#111110` | 同上 | `accent` 塗りの上の文字 |
| `muted` | `#595959` | `--mb-muted` | 副次の文字、既定の矢印 |
| `soft` | `#767676` | (派生) | 副ラベル、境界ラベル。白地で 4.5:1 を保つ最も薄いグレー |
| `rule` | `#DFDFDF` | `--mb-rule` | 細い罫線(線だけ。文字には使わない) |
| `rule-solid` | `#A5A5A5` | `--mb-faint` | 強めの罫線、基準線(白地で 2.5:1。文字・意味を担う記号には使わない) |
| `accent` | `#D63A2F` | `--mb-accent` | 強調。白地で 4.7:1 |
| `accent-tint` | `rgba(214,58,47,0.08)` | (派生) | `accent` 枠の塗り |
| `link` | `#2990DA` | `--mb-link` | HTTP/API 呼び出し、外部への矢印。白地で 3.4:1 なので線・矢印に使い、文字は `ink` |

`type-*.md` の `rgba(17,17,16,x)` などは、`ink`・`muted`・`accent` に不透明度を掛けた値です。`rgba(C, x)` の `C` は、下の「カテゴリ色」から選んだ値です。

### accent は文書全体で1箇所

html は赤い強調を1ページ1箇所までに制限しています。図の `accent` もこの予算に含めます。`type-*.md` にある「1図に focal 1〜2個」は、「文書全体で1個以内」と読み替えます。文書の赤い強調を図に使うなら、本文側では赤を使いません。図に focal が要らなければ、図では `accent` を使わず `ink` の太線と位置で示します。

### シリーズ(複数系列を持つ型)

radar・line・scatter などで系列を区別します。色相は使いません。濃淡と線種(破線・点線)の組み合わせで区別し、系列名は線の端に直接ラベルを置きます。濃淡だけで2系列を区別しません。

| スロット | 色 | 線種 |
|---|---|---|
| focal | `accent` `#D63A2F` | 実線 |
| `series-1` | `#595959` | 実線 |
| `series-2` | `#767676` | 破線 `6,3` |
| `series-3` | `#111110` | 点線 `2,3`(`stroke-linecap="round"`) |

系列の上限は4本(focal 1 + グレー3)です。`type-radar.md` と `type-line.md` の「5系列」は4系列に読み替え、超える場合は図を分けます。塗りは線と同じ色の不透明度 0.12〜0.18 を使います。

### カテゴリ色

`type-data-flow.md`・`type-process.md`・`type-medallion.md` などのノード単位の `color: "#hex"` は、次のグレーから選びます。色相は使いません。カテゴリの意味はラベルとタグの文字で伝え、色は補助にとどめます。

| 値 | 使いどころ |
|---|---|
| `#111110` | 最も強い区分(セキュリティ・ガバナンスなど) |
| `#595959` | 次点の区分 |
| `#767676` | 3番目の区分 |
| `#A5A5A5` | 4番目の区分(塗りと枠のみ。文字には使わない) |
| `#DFDFDF` | 作業・一時領域(塗りのみ。文字は `ink`) |

## 書体

文書側で Ubuntu Sans / Noto Sans JP / Ubuntu Mono を読み込み済みです。図は追加のフォントを読み込みません。SVG の `font-family` には次の文字列をそのまま書きます。

| 種別 | `font-family` |
|---|---|
| 名前(sans) | `'Ubuntu Sans', 'Noto Sans JP', sans-serif` |
| 技術的な値(mono) | `'Ubuntu Mono', 'Noto Sans JP', monospace` |

| 役割 | 書体 | サイズ | ウェイト | 用途 |
|---|---|---|---|---|
| `node-name` | sans | 12px | 600 | 人が読む名前 |
| `sublabel` | mono | 9px | 400 | ポート、プロトコル、URL、フィールド型 |
| `eyebrow` | mono | 7–8px | 500、字間 0.18em、大文字 | 種別タグ、軸ラベル |
| `arrow-label` | mono | 8px | 400、字間 0.06em | 矢印の注記 |

図に表題と注釈の書体はありません。表題は文書の見出しと `figcaption` が担います。mono は技術的な内容(ポート、コマンド、URL、型)だけに使い、名前は sans にします。

### 日本語ラベル

名前は `Noto Sans JP` に落ちる sans の指定で書きます。幅は文字ごとに数えます。**全角・全幅の文字は1em、それ以外は書体のラテン幅(sans 0.60em、mono 0.62em)**で、結合記号は0です。全角の句読点・括弧(`（）「」、。：`)も1emです。合計に font-size を掛けた幅へ余白を足し、4の倍数に切り上げます。

文字種ごとの集計は誤りのもとです。`認証 v2.1` は全角2文字と半角5文字なので、2em + 5文字分のラテン幅です。

- **副ラベルはラテンのまま。** ポート、プロトコル、フィールド型、URL は翻訳せず mono で書きます。説明文の副ラベルを日本語にする場合は、次の「切り替え」に従います
- **12px 未満にしない。** 12px に収まらない名前は、縮めずに名前を削ります
- **矢印ラベル・eyebrow・凡例は切り替える。** これらの枠は 7–8px の大文字 mono で、日本語には向きません。日本語のラベルは 12px の sans・ウェイト500・字間なし・大文字化なしにし、マスクの矩形も合わせて広げます(高さ 16px、幅は上の幅の見積もりを4の倍数に切り上げ)。同じ図のラテンのラベルは mono のままです
- **矢印ラベルは日本語で8文字以内。** ラテンの「14文字以内・大文字」の代わりです

## 線・角丸・間隔

| トークン | 値 | 用途 |
|---|---|---|
| `stroke-thin` | `0.8` | タグ枠、葉のノード |
| `stroke-default` | `1` | ほとんどの線 |
| `stroke-strong` | `1.2` | 強調の線 |
| `stroke-headline` | `2` | `accent` が使えないときの見出し経路(`ink`)。`stroke-default` と見分けがつく太さ |
| `radius-sm` | `4` | 小さいタグ |
| `radius-md` | `6` | ノードの箱 |
| `radius-lg` | `8` | コンテナ、リング |
| `grid` | `4` | 座標・寸法・間隔はすべて4の倍数(必須) |

線の太さと角丸は、図の密度に合わせて `component-samples.html` の例(stroke 2、rx 10)より細くしてかまいません。枠の `.mb-figure-frame` が図全体の外枠を担います。

## ノード種別と処理

型の仕様から、この名前で参照します。

| 種別 | 塗り | 線 |
|---|---|---|
| `focal`(文書全体で1個以内) | `accent-tint` | `accent` |
| `backend` | `paper` | `ink` |
| `store` | `ink @ 0.05` | `muted` |
| `external` | `ink @ 0.03` | `ink @ 0.30` |
| `input` | `muted @ 0.10` | `soft` |
| `optional` | `ink @ 0.02` | `ink @ 0.20` 破線 `4,3` |
| `security` | `ink @ 0.04` | `ink` 破線 `4,4`(`accent` は使わない) |

## 変更してはならない制約

- **有彩色は `accent` と `link` の2色だけ。** それ以外の色相を足さない。シンタックスハイライトとコード差分の機能色は図に関係しない
- **コントラスト:** `ink` と `muted` は `paper` 上で WCAG AA を満たす。`rule-solid` と `rule` は文字に使わない
- **図の地は白。** 図は `.mb-figure-frame`(白地、黒の罫線、角丸)に載せ、図自体に背景の矩形、ドットのパターン、枠は付けない
- **影・グラデーション・グローを使わない。**
- **記号は SVG で描く。** 絵文字や矢印文字を図記号に使わない
