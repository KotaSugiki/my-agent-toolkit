# レイアウトの寸法と型ごとの上限

`index.md` §5 から参照されます。4pxグリッドと、全型共通・型ごとの複雑さの上限を定めます。図を文書へ組み込む方法と大きさは [`output-spec.md`](output-spec.md) を参照します。

## 4pxグリッド

**4で割り切れるもの:** ノードの原点・幅・高さ、間隔、余白、軸・ガイド線・枠の位置。

**グリッド外にしてよいもの:** 文字サイズ(役割ごとの値は [`output-spec.md`](output-spec.md))、角丸、データから決まる位置、文字のベースライン、矢印のマーカー、1px線を鮮明にする `.5` のずれ、線の太さ、不透明度。

| 区分 | 使える値 |
|---|---|
| ノードの幅・高さ | 80, 96, 112, 120, 128, 140, 144, 160, 180, 200, 240, 320 |
| ノード間の間隔 | 20, 24, 32, 40, 48 |
| 箱の内側の余白 | 8, 12, 16 |
| 角丸 | 4, 6, 8 |

表の値は標準の寸法です。4の倍数であれば、ほかの値も使えます。ノードの高さは 48 以上、ノード間の間隔は 24 以上とし([`output-spec.md`](output-spec.md))、離れた2ノードをつなぐ長い経路では 48 を超える間隔も構いません。

## 複雑さの上限(図1枚あたり)

### 全型共通

| 項目 | 上限 |
|---|---|
| ノード | 9 |
| 矢印・遷移 | 12 |
| `accent` の要素 | 文書全体で1(`style-guide.md` の「accent は文書全体で1箇所」) |
| 注釈の吹き出し | 0(このスキルは扱わない) |

「ノード9」は、箱・点・バーなど、図の主要な要素の数の目安です。型ごとの上限がある型(タイムラインのイベント、ガントのバー、散布図の点など)では、その上限が先に効きます。

### 型ごとの上限

全型共通の上限に加えて適用します。意味パターンの上限は [`semantic-patterns.md`](semantic-patterns.md) にあり、厳しくする方向にだけ働きます。

| 項目 | 上限 |
|---|---|
| アーキテクチャ差分: 部品 / 関係 / 変更台帳の項目 | 8 / 10 / 8 |
| シーケンス: ライフライン | 5 |
| シーケンス: 複合フラグメント | 1(既定)。2は、それぞれが単一領域の `opt` / `loop` の場合のみ |
| シーケンス: `alt` 領域 / フラグメントの入れ子 | 2 / 1 |
| スイムレーン: レーン | 5 |
| タイムライン: イベント | 7 |
| プロセス: レーン / ステップ | 5 / 6(908幅に収まる数。型の式を計算し直す) |
| 四象限: 項目 | 12 |
| 棒グラフ: 棒 | 8 |
| 折れ線: 系列 | 4 |
| ガント: タスク | 12 |
| 散布図: 点 | 30 |

超える場合は、図を2枚に分けます(概要と詳細)。

## 文書内の構成

文書の `h2` の下に `<figure class="mb-figure">` を置きます。図の表題・凡例の帯・キャプションの役割は次のとおりです。

1. 表題は文書の見出しと `figcaption`(図番号と説明)が担う。図に表題や見出し行を描かない
2. 凡例は図の下端の水平な帯。図の内側に浮かせない(`primitives-core.md` の Legend)
3. サマリーカードやフッターは文書側のコンポーネントを使い、図には含めない
