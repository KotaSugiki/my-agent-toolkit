# deep-code-reading

選定したリポジトリ全体、または指定した箇所のアーキテクチャと基本的な動作フローを理解するためのスキルです。解説の根拠として、該当するファイルや行へのコードポインターを付けます。

## 使い方

調べたいリポジトリと範囲を指定して、エージェントに解説を依頼します。リポジトリを参照できる状態にしておいてください。指定箇所がある場合は、ファイル、ディレクトリ、機能名などで示せます。

依頼例:

- 「このリポジトリを deep-code-reading で調べ、主要な構成要素と起動から処理完了までの基本フローをコードポインター付きで説明してください」
- 「このリポジトリの `src/auth/` を deep-code-reading で調べ、全体の中での役割とログイン処理の流れを説明してください」

エージェント向けの指示は [SKILL.md](SKILL.md) に記載しています。
