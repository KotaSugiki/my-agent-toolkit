# html-explainer の使用例

[html-explainer](../../skills/html-explainer/README.md) の12種の型のうち、9種(architecture-delta・sequence・process・line・scatter・quadrant・swimlane・timeline・gantt)を使って作成した説明文書の例です。注文確定の処理を、同期の連鎖呼び出しから、メッセージキュー経由の非同期処理へ移す話を、バックエンド開発の新人向けに説明しています。9つの図と、表、用語リストを含みます。

## 開き方

`20261008-async-order-migration.html` をブラウザで開きます。書体、数式、コードの色付けは外部から読み込むため、オンラインで開きます。

HTMLは、文書のCSSなどを `../../skills/html-explainer/design-system/` から読み込みます。スキルの「利用者が共有アセットのパスを指定した場合は、そのパスを優先する」規則に沿った配置で、`design-system/` の複製を避けています。HTMLを別の場所へ移す場合は、読み込みパスを直すか、`design-system/` を隣へコピーします。

## 作成方法と注意

スキルを読んだことのないエージェント(型ごとに1〜3図を担当)に、`SKILL.md` の手順だけで図を描かせ、共通の筋書き(構成、日付、数値)に合わせて1つの文書にまとめました。文書の文章は、各エージェントの説明文を土台に、まとめる際に書き直しています。

- 文書内の数値、日付、点の位置は、すべて説明用の仮の値です。図4の応答時間、図5の22点、図6の配置、図8・図9の日付を含みます
- 赤い強調は、図4の「非同期方式」の線だけです。ほかの図で強調が必要な箇所(図3の境目、図6の「最初に移す」領域、図7の差し戻し、図8・図9の関門)は、`ink` の太さ・枠・白抜きの輪で示しています
- 図は、スキルの指示を直す前の版で描いたものです。直した内容は `skills/html-explainer/provenance.md` に記録しています。四象限図(図6)だけ、直した規則(軸の両端の「低」「高」)に合わせて手で追記しました。そのほかの図は、現在の指示で描き直すと、細部(矢印のマーカーの大きさ、凡例の位置など)が変わることがあります
- 描画の確認は、幅1400pxと、幅390px(図は枠の中で横スクロール)で行いました。実機のスマートフォンと印刷は確認していません
