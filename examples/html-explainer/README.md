# html-explainer の使用例

[html-explainer](../../skills/html-explainer/README.md) で作成した説明文書の例です。注文が確定するまでの仕組みを、バックエンド開発の新人向けに説明しています。アーキテクチャ図、フローチャート、棒グラフの3つの図と、コードブロック、数式、用語リストを含みます。

## 開き方

`20261008-online-shop-order-confirmation.html` をブラウザで開きます。書体、数式、コードの色付けは外部から読み込むため、オンラインで開きます。

HTMLは、文書のCSSなどを `../../skills/html-explainer/design-system/` から読み込みます。スキルの「利用者が共有アセットのパスを指定した場合は、そのパスを優先する」規則に沿った配置で、`design-system/` の複製を避けています。HTMLを別の場所へ移す場合は、読み込みパスを直すか、`design-system/` を隣へコピーします。

## 作成方法と注意

次の依頼で、スキルを読んだことのないエージェントに、`SKILL.md` の手順だけで作らせました。

```text
オンラインショップで注文が確定するまでの仕組みを、HTML の説明文書にしてください。読者はバックエンド開発の新人です。
```

- 生成後に手で直したのは、`design-system/` の読み込みパスだけです
- 図3の遅延の数値は、説明のための仮の値です。実測ではありません
- この例は、試作の結果を踏まえてスキルの指示を直す**前**の版で作成しました。現在の指示で作り直すと、ページ骨格・凡例・矢印のマーカーなどの細部が変わることがあります
- 描画の確認は、幅1400pxで行いました。幅390pxでは図が枠の中で横スクロールになります
