# 実験支援エージェント

仮説の検討、条件を変えた実験、評価・分析、レポート作成、人間のフィードバックを支援します。対象分野の知識、実行方法、評価方法は導入先で与えます。

## 4担当と親の役割

次の表の入力・成果物は、導入先に保存する情報です。各担当の作業範囲と完了条件はリンク先に定めています。

| 名前 | 担当 | 入力 | 成果物 |
| --- | --- | --- | --- |
| [experiment-planner](roles/experiment-planner.md) | 実験計画 | 前提、継続する目標値、前回の結果とフィードバック | Markdownの計画、指標・目標値と根拠、比較条件、判定基準 |
| [experiment-runner](roles/experiment-runner.md) | 実験実行 | 実行可能な計画、データ、環境 | 設定、実行記録、結果、失敗ログ |
| [experiment-analyst](roles/experiment-analyst.md) | 評価・分析 | 計画時の判定基準、実行記録、結果 | 仮説を支持する結果、反する結果、判断不能、限界、追加検証案 |
| [experiment-reporter](roles/experiment-reporter.md) | レポート作成 | 目的、計画、実行、評価と根拠 | 簡潔なHTMLレポート、グラフ・詳細表示、参照資料、判断事項 |

親エージェントは [進行手順](workflow.md)を読み、4担当を順番に呼びます。担当の成果物を確認し、人間のフィードバックを次の計画へ反映します。各担当は個別にも呼べます。

## 導入と前提条件

エージェントの導入は、Claude CodeまたはCodexのマーケットプレイスから [experimentsプラグイン](../../plugins/experiments/README.md)を追加する2通りに統一します。前提条件、導入・確認・更新・削除は [共通の導入ガイド](../../docs/agent-plugins.md)を参照してください。

利用先には、対象分野のデータ、実行環境、評価手順を用意します。プラグイン導入だけでは実験の前提文書を作成しません。初回の整理では質問への回答を待ち、確認した内容を保存します。

Claude Codeでは、2スキルと4担当の認識を確認済みです。Codexではプラグインの導入と2スキルの認識まで確認済みです。Codexの4担当の登録と全体進行は未確認です。

## 使い方と成果物

前提整理用の `setup-experiments` と、全体進行用の `run-experiments` をプラグインに同梱します。呼び出し方と依頼例は [プラグインの使い方](../../plugins/experiments/README.md)を参照してください。進行手順と記録形式も同梱するため、利用者が別途コピーする必要はありません。

計画は草案・確認待ちでもMarkdownファイルへ保存します。正式な保存先が未定なら一時ファイルを使い、場所を返します。

レポートはHTMLで保存し、冒頭に短い結論、主要な結果、判断事項を置きます。比較はグラフや短い表で示し、詳細は折りたたみや条件・指標の切り替えで確認できます。利用可能な `html` スキルがあれば使います。希望するスキルの場所や表示方法を依頼に添えられます。

実験記録とレポートは利用先のプロジェクトに保存し、プラグインの削除後も保持します。分野の異なる架空の例と、対話・不足・失敗の確認項目は [利用例](examples.md)を参照してください。

## 保守と検証

編集元は [registry.toml](registry.toml)、[共通指示](common.md)、[記録形式](../../skills/setup-experiments/references/records.md)、`roles/` の各担当です。配布物の生成と公開は [導入ガイドの保守担当者向け手順](../../docs/agent-plugins.md#保守担当者向けの生成と公開)にまとめています。生成スクリプトによる個別配置は、利用者向けの導入方法として扱いません。

### 確認範囲（2026/10/06）

Python 3.11.9で8件の自動テストを確認しました。生成内容の一致、構文、上書き拒否、更新、再実行、読み取り専用の確認、付属資料の参照、配布一覧との整合を検証しています。

Claude Code 2.1.291では配布物の厳格な検証、ローカルマーケットプレイスからの導入、初期化応答で2スキルと4担当の認識を確認しました。Codex CLI 0.160.1では同じ配布物の導入・有効化と、`skills/list` で2スキルの認識を確認しました。Codexの一時配布物では版を変更した後の再導入と削除も確認しました。

検証には一時環境を使い、既存のユーザー設定は変更していません。GitHubからの導入と、モデルによる対話・実験・HTMLレポートの動作は未検証です。Codexで4担当がカスタムエージェントとして登録されるかも未確認です。
