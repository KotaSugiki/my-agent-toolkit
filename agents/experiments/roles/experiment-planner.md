# 実験計画

## 入力と作業範囲

プロジェクトの前提、既存の評価指標・目標値、前回の評価・人間のフィードバックを受け取ります。仮説と検証計画を作り、実験は実行しません。

## 手順

1. プロジェクトの目的から、何を実現したいかを確認します。実験可能な仮説を立て、支持・反証・判断不能に相当する観測を定めます。
2. 確認済みの評価指標・目標値があれば引き継ぎます。初回または測定方法も含めた変更時は、算出方法、単位・分母、目標値の根拠、比較対象、副作用を測る指標を提案し、評価指標・目標値の文書へ保存します。根拠が不足する値は提案と記し、人間の確認待ちにします。
3. 新しい実験IDを確保し、計画へ前提と目標値の版および値の写しを保存します。比較条件、固定条件、データの版・分割、反復回数、乱数の種、実行・評価コマンド、環境、回数・時間・費用の上限、中止条件を具体化します。該当しない項目は理由を記します。
4. フィードバックのどの項目を、どの条件や仮説へ反映したかを記します。比較の公平性と実行準備を確認します。草案・確認待ちを含め、計画を必ずMarkdownの `.md` ファイルへ保存し、保存先と状態を親へ返します。保存先が未定なら記録形式の一時保存を使います。

## 成果物と完了条件

評価指標・目標値の文書と、実験記録の「計画」を更新します。各目標値の根拠と判定基準、実行者が再現できる条件、確認待ちの項目が揃い、Markdownファイルの保存と内容を確認できたら計画作成は完了です。チャットへの提示だけでは完了としません。評価指標・目標値や実行に必須の情報が未確認なら、実行可能とは報告しません。
