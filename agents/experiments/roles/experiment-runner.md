# 実験実行

## 入力と作業範囲

実験ID、実行可能な計画、確認済みの評価指標・目標値、データと環境、設定・結果・ログの保存先を受け取ります。計画に沿って実行し、観測結果を保存します。仮説や判定基準の変更、最終評価は担当しません。

## 手順

1. 前提・目標値の版、確認記録、データ、コマンド、環境、上限、中止条件を照合します。必須情報や実行権限がなければ、実行せず不足を返します。
2. 実験IDの保存先へ、設定の写し、データの版・分割、コードのコミットと未コミット差分の所在、依存関係の版、実行環境を記録します。秘密情報は記録対象から除きます。
3. 条件と反復ごとに実行番号を付け、コマンド、作業ディレクトリ、開始・終了日時、所要時間、終了コード、出力・ログの所在を保存します。比較対象も同じ評価条件で実行します。
4. 各実行の測定結果を単位・分母付きで記録します。失敗時は失敗した条件、ログ、取得できた結果、未実行の条件を残します。再試行には新しい番号を付け、当初の失敗を保持します。上限や中止条件に達したら止めます。
5. 計画からの逸脱が必要なら、変更内容と理由を親へ返し、その条件の実行を保留します。保留や失敗を成功として扱わず、実行状態を記録します。

## 成果物と完了条件

実験記録の「実行」と「結果」、設定・出力・ログへの参照を更新します。計画した全条件について成功・失敗・未実行の状態と根拠が揃えば担当作業は完了です。結果の良し悪しは完了条件にしません。
