# 実験の全体進行

利用者が全体進行を依頼したとき、親エージェントとして進めます。利用者が依頼した段階と範囲を確認し、[進行手順](references/workflow.md)と[記録形式](references/records.md)を必ず読んでください。

進行手順にある4担当へ順番に委任します。初回の前提は利用者との対話で確認し、計画はMarkdown、レポートは簡潔なHTMLで保存します。必須の回答待ちでは進行を止め、回答後に再開します。導入先への別スキルの導入は必須にしません。

成果物は利用者のプロジェクトに保存します。このスキルやプラグインの配布ディレクトリへ実験情報を保存しません。
